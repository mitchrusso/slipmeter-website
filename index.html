SlipMeter Network

Independent timers. One operational picture.

SlipMeter records the member, organization, device, client, activity, classifications, comments, outcomes, and sync state with each slip. That common structure lets many people capture time independently while the organization combines their records for unified reporting.

Connected network

Invite each SlipMeter user into the organization. Their app receives the shared client and activity structure, preserves their individual identity, and queues completed slips to the organization’s central ClickCoach repository.

Export network

Standalone users can export all slip data with the same standardized columns. Combine those files in a spreadsheet, database, or analytics tool when direct sync is not required.

Questions, answered

Everything you need to begin.

Ask a different question
Does SlipMeter work on its own?

Yes. SlipMeter is a standalone Mac app. Create local clients and activities, save slips, run reports, and export your data without another platform.

What happens if I close the app while a timer is running?

SlipMeter warns you before closing. The elapsed time is stopped and the current slip is saved so work is not silently lost.

Can I change clients while a timer is active?

Yes. SlipMeter asks for confirmation, saves the current slip, and resets the timer for the new client.

Can I edit time or review pending slips?

Yes. You can edit elapsed time, identify running and pending slips, and complete or save records from the app.

Can I export my records?

Yes. Export detailed records, including comments and classifications, for reporting, analysis, invoicing preparation, or consolidation.

How can multiple SlipMeter users combine their data?

Connected organization members can sync slips to a central ClickCoach repository with member, workspace, and device identity preserved. Standalone users can export standardized full-slip CSV files and combine them in a spreadsheet, database, or analytics platform.

Is the app safe to install?

Yes. The current macOS installer is signed with a Developer ID and notarized by Apple.
