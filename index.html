Ask a different question
Does SlipMeter work on its own?

Yes. SlipMeter is a standalone Mac app. Create local clients and activities, save slips, run reports, and export your data without another platform.

What happens if I close the app while a timer is running?

SlipMeter warns you before closing. The elapsed time is stopped and the current slip is saved so work is not silently lost.

Can I change clients while a timer is active?

Yes. SlipMeter asks for confirmation, saves the current slip, and resets the timer for the new client.

Can I edit time or review pending slips?

Yes. You can edit elapsed time, identify running and pending slips, and complete or save records from the app.

Can I export my records?

Yes. Export detailed records, including comments and classifications, for reporting, analysis, invoicing preparation, or consolidation.

Do we need SlipMeter Network to combine team data?

No. Each person can export detailed slips as a CSV file. A manager can collect and combine those files in Excel, Google Sheets, a database, or another reporting tool. This manual “sneakernet” approach works even when the team does not use cloud synchronization.

How does SlipMeter Network work?

SlipMeter Network is an optional cloud service that does not require ClickCoach. Its secure repository, organization dashboard, device controls, invitations, and unified reports are live in early access. Automatic synchronization from the installed Mac app is the next connector; until that update ships, existing local SlipMeter operation is unchanged.

Can an AI assistant report on our SlipMeter data?

Yes. Organization administrators can create a revocable, read-only MCP credential from the SlipMeter Network dashboard. Compatible assistants can summarize time, report by client or member, find incomplete slips, check Network status, and export filtered CSV data without modifying any records.

What will SlipMeter Network cost?

The first year will be included with every active SlipMeter license. After that, Network will renew for $9.97 per year per license. One named-user license covers up to two computers, plus SlipMeter Mobile when it becomes available.

Is the app safe to install?

Yes. The current macOS installer is signed with a Developer ID and notarized by Apple.
